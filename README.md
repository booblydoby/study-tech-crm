# Study Center CRM

CRM-система для учебного центра: студенты, учителя, группы, расписание, оплаты и отчёты.

Этот гайд написан для людей **без опыта в разработке**. Следуйте шагам по порядку.

---

## Что нужно установить один раз

### 1. Node.js (версия 20 или новее)

1. Откройте в браузере: https://nodejs.org/
2. Скачайте версию **LTS** (рекомендуемая).
3. Запустите установщик и нажимайте «Далее» с настройками по умолчанию.
4. Проверьте установку — откройте **PowerShell** (Win + X → «Терминал» или «PowerShell») и введите:

```powershell
node -v
```

Должно показать что-то вроде `v20.x.x` или `v22.x.x`.

### 2. pnpm (менеджер пакетов)

В том же окне PowerShell выполните:

```powershell
corepack enable
corepack prepare pnpm@9.15.4 --activate
pnpm -v
```

Должна появиться версия `9.15.4` (или близкая).

### 3. PostgreSQL (база данных)

**Вариант А — проще: через Docker Desktop** (если не хотите ставить PostgreSQL отдельно)

1. Скачайте Docker Desktop: https://www.docker.com/products/docker-desktop/
2. Установите и перезагрузите компьютер при необходимости.
3. Запустите Docker Desktop и дождитесь, пока он полностью загрузится.

**Вариант Б — установить PostgreSQL напрямую**

1. Скачайте: https://www.postgresql.org/download/windows/
2. При установке запомните пароль пользователя `postgres`.
3. Порт оставьте `5432`.

## Первый запуск проекта (пошагово)

### Шаг 1. Откройте папку проекта в терминале

В PowerShell:

```powershell
cd "C:\Users\Sergey Shuvalov\Desktop\Study Tech"
```

(Если проект лежит в другом месте — укажите свой путь.)

### Шаг 2. Создайте файл настроек `.env`

```powershell
Copy-Item .env.example .env
```

Файл `.env` хранит пароли и адреса — **не отправляйте его никому** и не публикуйте в интернете.

Для локального запуска можно оставить значения из примера как есть.

### Шаг 3. Запустите базу данных

#### Если используете Docker (рекомендуется)

Только PostgreSQL:

```powershell
docker compose up -d postgres
```

Подождите 10–15 секунд, пока база поднимется.

#### Если PostgreSQL установлен на компьютере

1. Откройте **pgAdmin** или любой клиент PostgreSQL.
2. Создайте базу `study_crm` и пользователя `study` с паролем `study`  
   **или** измените строку `DATABASE_URL` в файле `.env` под свои данные.

Пример для локальной БД:

```
DATABASE_URL="postgresql://study:study@localhost:5432/study_crm?schema=public"
```

### Шаг 4. Установите зависимости и подготовьте базу

Одна команда (может занять 2–5 минут при первом запуске):

```powershell
pnpm setup
```

Что она делает:
- скачивает библиотеки проекта;
- создаёт таблицы в базе;
- добавляет тестовые данные (админ, учитель, студент).

Если команда `pnpm setup` выдала ошибку про базу — убедитесь, что PostgreSQL запущен (шаг 3).

### Шаг 5. Запустите сайт и API

```powershell
pnpm dev
```

Дождитесь сообщений вроде:
- API слушает порт `4000`
- Next.js готов на `http://localhost:3000`

### Шаг 6. Откройте в браузере

| Адрес | Что это |
|-------|---------|
| http://localhost:3000 | Сайт CRM (вход, интерфейс) |
| http://localhost:4000/api/v1 | API (для разработчиков) |
| http://localhost:4000/docs | Документация API (только в режиме разработки) |

## Частые проблемы

### «pnpm не является внутренней командой»

Выполните снова:

```powershell
corepack enable
corepack prepare pnpm@9.15.4 --activate
```

Перезапустите PowerShell.

### «Cannot connect to database» / ошибка Prisma

1. Проверьте, что PostgreSQL запущен: `docker compose ps` (статус `healthy` у postgres).
2. Проверьте `DATABASE_URL` в файле `.env`.
3. Повторите: `pnpm db:migrate:deploy` и `pnpm db:seed`.

### Порт 3000 или 4000 занят

Закройте другие программы, использующие эти порты, или измените `API_PORT` / запуск web в `apps/web/package.json`.

### Страница не открывается после `pnpm dev`

Подождите 30–60 секунд после запуска. Убедитесь, что в терминале нет красных ошибок.

### Забыли пароль админа

Пересоздайте тестовые данные:

```powershell
pnpm db:seed
```

(Старые демо-аккаунты обновятся, если email совпадает.)

## Полезные команды

| Команда | Для чего |
|---------|----------|
| `pnpm dev` | Запуск сайта + API для разработки |
| `pnpm build` | Сборка проекта (проверка, что всё компилируется) |

## Безопасность перед реальным использованием

1. Смените `JWT_ACCESS_SECRET` в `.env` на длинную случайную строку (минимум 24 символа).
2. Смените пароли `ADMIN_PASSWORD`, `DEMO_TEACHER_PASSWORD`, `DEMO_STUDENT_PASSWORD`.
3. Не публикуйте файл `.env` в интернете.
4. В продакшене отключите Swagger (`SWAGGER_ENABLED=false`).
